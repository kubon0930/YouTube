# やま幸 YouTube チャンネル イントロ

豊洲市場のまぐろ仲卸「やま幸」向けの、約6秒のオープニング用アニメーションイントロです。
外部ファイル不要の**単体HTML**で、ブラウザで開けばそのまま再生されます。画面録画すれば動画のオープニングとして使えます。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 自動で約6秒のイントロが再生される
3. 右下の「▶ もう一度再生」でリプレイ

## 動画として書き出す（録画）

外部ソフト不要で、OS標準の画面録画で十分です。

- **Windows**: `Win + Alt + R`（Xbox Game Bar）
- **Mac**: `Shift + Cmd + 5` → 「収録」
- ブラウザは**全画面（F11）**にすると16:9のステージがきれいに収まります

より高画質・自動化したい場合は、以下のように Playwright / ffmpeg での録画も可能です（任意）。

## 演出の内容（タイムライン）

| 時間 | 演出 |
|------|------|
| 0.0s〜 | 墨色の背景に市場の光（金色のハロー）が広がる |
| 0.35s〜 | 屋号「やま幸」が金文字で一文字ずつ浮かび上がる |
| 1.15s〜 | 上下に金の細ライン（暖簾のライン） |
| 1.5s〜 | 「豊洲市場・まぐろ仲卸」の小見出し |
| 1.75s〜 | 赤い落款「本鮪」がスタンプされる |
| 2.0s〜 | チャンネル名「YAMAKOH CHANNEL」 |
| 〜5.5s | 下部の赤い再生バーが伸びきる |
| 6.0s〜 | 暗転してフェードアウト |

## デザインの狙い

- **色**: 墨（黒）× 金 × 鮪の赤（中トロ）で、和の高級感と YouTube らしさを両立
- **書体**: 明朝体（游明朝 / ヒラギノ明朝 など、端末標準フォントを使用）
- **モチーフ**: 落款（印）・暖簾のライン・市場の照明

## カスタマイズ

`index.html` 冒頭の `:root` で色を、`.eyebrow` / `.brand` / `.sub` / `.seal` の文言を
書き換えるだけで、屋号やキャッチコピーを差し替えられます。
