# やま幸 / YAMAYUKI — YouTube チャンネル イントロ

やま幸のブランドカラー（ブルー #0064aa／グリーン #46b446）に合わせた、約9.5秒のシネマティックなオープニングです。
**深い青の海に光のコースティクスが揺らめき、実写の本マグロが1匹、ブランドロゴの背後を悠然と横切る** 構成。
清潔感と品格があり、海外にも通用します。

## マグロは実写を合成しています

3Dで一から作るCG（SDF）では写真のような本マグロにはなりません。そこで、**ご提供いただいたマグロの参考写真から本体を切り抜き**、
深海シーンに合成しています。

- 背景（フラッドフィル）を除去して輪郭を収縮 → クリーンなアルファ切り抜き
- 水中カラーグレーディング（クールな青へ）
- 体表を流れる光（コースティクス）と上辺のリムライトを重ねる
- 遊泳のうねり（テールスウェイ＝尾側ほど大きく揺れる縦ストリップ変形）＋ゆったりした上下動
- 海（背景・光・god ray）は WebGL のリアルタイム描画

これらを1枚のキャンバスに合成し、**ブラウザだけで動画（WebM）を書き出せます**。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨・WebGL必須）で開く
2. 自動で本編が再生される（初回は音声はブラウザ制限で無音）
3. **「▶ 再生（音あり）」** … 音付きで頭から再生
4. **「⬇ 動画をダウンロード（WebM）」** … 約9.5秒を録画して `yamayuki-intro.webm` を保存

> MP4 が必要な場合は `ffmpeg -i yamayuki-intro.webm yamayuki-intro.mp4` で変換できます。

## 差し替え・カスタマイズ

- **別のマグロ写真に差し替える**: 白背景の写真を用意し、同じ手順（切り抜き→RGB(JPEG)＋アルファ(PNG)に分離→データURI化）で
  `index.html` の `#tuna_rgb` / `#tuna_alpha` を置換
- 尺: 冒頭の `END`（秒）／ マグロの大きさ・速度・高さ: `drawTuna()` 内の `dw` / `prog` / `cy`
- 配色: `#46b446`（緑）/ `#0064aa`（青）、海の色は WebGL シェーダ内
- タイミング: 各 `seg(t, 開始, 長さ)`

> `intro.artifact.html` はライブプレビュー（Artifact）用の同一内容ファイルです。
> 動画ダウンロードはサンドボックス制限で無効な場合があるため、書き出しは `index.html` をローカルで開いてご利用ください。
