# やま幸 / YAMAYUKI — YouTube チャンネル イントロ

やま幸のブランドカラー（ブルー #0064aa／グリーン #46b446）に合わせた、約9.5秒のシネマティックなオープニングです。
**深い青の海に光のコースティクスが揺らめき、本マグロが1匹ゆっくりと横切り、ブランドロゴが浮かび上がる** ——
清潔感と品格のある、海外にも通用する構成にしています。

海（背景・光・マグロ）は **WebGL によるリアルタイム 3D レンダリング**（レイマーチング）で本物の陰影・反射を描画。
ロゴ・文字・進行演出は 2D で合成し、両者を1枚のキャンバスに束ねて、**ブラウザだけで動画（WebM）を書き出せます**。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨・WebGL必須）で開く
2. 自動で本編が再生される（初回は音声はブラウザ制限で無音）
3. **「▶ 再生（音あり）」** … 音付きで頭から再生
4. **「⬇ 動画をダウンロード（WebM）」** … 約9.5秒を録画して `yamayuki-intro.webm` を保存

> 画面録画ソフトは不要です。ボタンが `1920×1080 / 30fps / 音声付き` の WebM を生成します。
> MP4 が必要な場合は `ffmpeg -i yamayuki-intro.webm yamayuki-intro.mp4` で変換できます。

## 技術

- **3D レンダリング**: WebGL フラグメントシェーダによるレイマーチング
  - 本マグロ … SDF（メタボール胴＋二又尾＋背びれ・胸びれ・尻びれ）を、逆陰影（背は鋼青／腹は銀白）＋
    ウェットスペキュラ＋フレネルのリムライトで陰影付け。表面に水面のコースティクスを投影
  - 海 … 深度グラデーション＋スクリーン空間の god ray ＋レイヤードコースティクス＋被写界フォグ
- **合成サウンド**: Web Audio API による完全合成（外部音源ファイル不要・著作権フリー）
- **書き出し**: `canvas.captureStream()` ＋ Web Audio の `MediaStreamDestination` を `MediaRecorder` で合成し WebM 生成
- ブランドロゴは公式ロゴ（白版）をそのまま使用。アクセントはブランドグリーン

## カスタマイズ

`index.html` 内の各パラメータで調整できます。
- 尺: 冒頭の `END`（秒）
- 配色: `background()` の海の色、`#46b446`（緑）/ `#0064aa`（青）
- マグロの動き: `fishPos` / `fishYaw`、大きさは `const float S`
- タイミング: 各 `seg(t, 開始, 長さ)`
- 文言: `tracked('TOYOSU FISH MARKET', ...)`

> `intro.artifact.html` はライブプレビュー（Artifact）用の同一内容ファイルです。
> 動画ダウンロードはサンドボックス制限で無効な場合があるため、書き出しは `index.html` をローカルで開いてご利用ください。
