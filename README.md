# やま幸 / YAMAYUKI — YouTube チャンネル イントロ

豊洲市場のまぐろ仲卸「やま幸」向けの、約8秒のシネマティックなオープニングイントロです。
海外視聴者にも通用するよう、和の高級感（明朝の屋号・金箔・落款）と英字ワードマークを両立させています。
外部ファイル不要の**単体HTML**で、ブラウザで開けばそのまま再生されます。画面録画すればそのまま動画のオープニングに使えます。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 自動で約8秒のイントロが再生される
3. 右下の「▶ Replay」でリプレイ

## 動画として書き出す（録画）

外部ソフト不要で、OS標準の画面録画で十分です。

- **Windows**: `Win + Alt + R`（Xbox Game Bar）
- **Mac**: `Shift + Cmd + 5` → 「収録」
- ブラウザは**全画面（F11）**にすると16:9のステージがきれいに収まります

## デザインの狙い

- **色**: 墨（黒）× 深い藍（深海）× 金箔 × 鮪の赤（中トロ・落款）。国際的な高級ブランドの質感を意識
- **書体**: 屋号は明朝体、英字は Optima / Baskerville 系の上品なセリフ（端末標準フォントを使用）
- **モチーフ**: 金の額装・落款（印）・市場の光・舞い上がる金粉
- **技術**: 背景の粒子は Canvas、屋号の光沢はメタリックなグラデーションのスイープ。`prefers-reduced-motion` にも対応

## カスタマイズ

`index.html` 冒頭の `:root` で配色を、`.eyebrow` / `.brand` / `.wordmark` / `.tagline` / `.seal`
の文言を書き換えるだけで、屋号・英字表記・キャッチコピーを差し替えられます。
尺は各アニメーションの `animation-delay` と `.progress` / `#fadeout` の時間で調整できます。

> `intro.artifact.html` はライブプレビュー（Artifact）用の同一内容ファイルです。
