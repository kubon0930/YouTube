# やま幸 / YAMAYUKI — YouTube チャンネル イントロ

豊洲市場のまぐろ仲卸「やま幸」向けの、約9秒のシネマティックなオープニングイントロです。
海外視聴者にも通用するよう、和の高級感（明朝の屋号・金箔・落款）と英字ワードマークを両立。
**全編を1枚のCanvasに描画**し、**合成サウンド**を同期、**ブラウザだけで動画（WebM）を書き出せる**のが特長です。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge 推奨）で開く
2. 自動で本編が再生される（初回は音声はブラウザ制限で無音）
3. **「▶ 再生（音あり）」** … 音付きで頭から再生
4. **「⬇ 動画をダウンロード（WebM）」** … 約9秒を録画して `yamayuki-intro.webm` を保存

> 画面録画ソフトは不要です。ダウンロードボタンが `1920×1080 / 30fps / 音声付き` の
> WebM を生成します。YouTube はそのまま WebM をアップロードできます。
> MP4 が必要な場合は `ffmpeg -i yamayuki-intro.webm yamayuki-intro.mp4` で変換できます。

## 技術

- **描画**: すべて Canvas 2D（1920×1080）。テキスト・金箔・粒子・光・落款まで手描き
- **金箔**: 縦方向のメタリックグラデ＋加算合成の光沢スイープ
- **サウンド**: Web Audio API による完全合成（外部音源ファイル不要・著作権フリー）
  - 太鼓＝低周波オシレータ＋ノイズ、きらめき＝倍音サイン、風切り＝バンドパス掃引ノイズ
- **書き出し**: `canvas.captureStream()` ＋ Web Audio の `MediaStreamDestination` を
  `MediaRecorder` で合成し、映像＋音声入りの WebM を生成
- `prefers-reduced-motion` 相当に配慮した穏やかな演出

## カスタマイズ

`index.html` の各描画関数（`brand` / `eyebrow` / `wordmark` / `tagline` / `seal`）の文言・座標、
冒頭の色（`#c9a25a` 金、`#c31f2d` 赤 など）、`seg(t, 開始, 長さ)` のタイミングを書き換えるだけで、
屋号・英字表記・キャッチコピー・尺を調整できます。`END` で全体の尺（秒）を変更できます。

> `intro.artifact.html` はライブプレビュー（Artifact）用の同一内容ファイルです。
> ダウンロードはブラウザのサンドボックス制限で無効な場合があるため、書き出しは `index.html` をローカルで開いてご利用ください。
